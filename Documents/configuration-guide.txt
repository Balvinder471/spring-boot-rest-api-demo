===============================================================================
  Spring Boot REST API - Configuration Guide
===============================================================================

Application Properties
----------------------
  Configuration file location: WebApp/BOOT-INF/classes/application.properties

Database Configuration
----------------------

  For H2 (Development / Embedded):
    spring.datasource.url=jdbc:h2:mem:testdb
    spring.datasource.driver-class-name=org.h2.Driver
    spring.jpa.database-platform=org.hibernate.dialect.H2Dialect

  For MySQL (Production):
    spring.datasource.url=jdbc:mysql://localhost:3306/restapi_db
    spring.datasource.username=root
    spring.datasource.password=your_password
    spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
    spring.jpa.database-platform=org.hibernate.dialect.MySQLDialect

Server Configuration
--------------------
  server.port=8080                   -- HTTP port (default: 8080)
  server.servlet.context-path=/      -- Application context path

JPA / Hibernate
---------------
  spring.jpa.hibernate.ddl-auto=update   -- Auto-create/update tables
  spring.jpa.show-sql=true               -- Log SQL statements

JWT Security
------------
  jwt.secret=your-secret-key        -- JWT signing secret (change in production!)
  jwt.expiration=86400000            -- Token expiration in ms (default: 24 hours)

Logging
-------
  logging.level.root=INFO
  logging.level.com.example=DEBUG
  logging.file.name=application.log

Environment-Specific Overrides
------------------------------
  You can override any property via environment variables using the
  Spring relaxed binding convention:
    e.g., SPRING_DATASOURCE_URL=jdbc:mysql://prod-host:3306/prod_db
